# 透光幻影 · Ethereal Backlight

用于写实幻想图像创作的 Codex 风格技能，以强局部高光、透射光、克制色彩与朦胧景深，表现轻盈、通透的光影美感。

## 风格

- **定向侧光与侧逆光**：边缘和透光处形成明亮高光，背光处保留较深阴影与丰富中间调。
- **克制色彩**：低至中低饱和，暖白高光与偏冷阴影相映，同时保留鲜明光比。
- **真实材质**：薄材呈现透光与叠层，反光细腻，保持材质本身的厚薄、透明度与纹理。
- **朦胧层次**：焦点细节可辨，背景柔和虚化，最亮处轻微晕散，保留空间深度。

技能定义光线、色彩、材质与景深。主体、造型、服装、动作、道具、场景和构图由每次创作请求独立指定。

## 安装

将此仓库克隆到 Codex 的个人技能目录：

```sh
git clone https://github.com/PolarisLight/ethereal-backlight.git ~/.codex/skills/ethereal-backlight
```

如果使用了自定义 Codex 主目录，将目标路径换成该目录下的 `skills/ethereal-backlight`。目标文件夹已经存在时，请先检查本地内容，保留自己的修改。

也可以下载仓库 ZIP，解压后将包含 `SKILL.md` 的文件夹命名为 `ethereal-backlight`，放入个人技能目录。

## 使用

在支持该技能的 Codex 会话中输入：

```text
使用 $ethereal-backlight，生成一位穿红白轻纱的仙女，雪片在她前后自然飘落。
```

```text
使用 $ethereal-backlight，为一只透明玻璃花瓶设计图像提示词，背景为虚化的灰蓝色。
```

仅请求提示词时输出提示词；请求生图时调用可用的图像生成工具。默认纯文生图，需要编辑现有图片时在请求中明确说明。

实际效果取决于所用图像模型和当次内容描述，可根据成图针对性调整高光范围、光比、饱和度和景深。
